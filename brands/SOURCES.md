# Brand icon sources

Vector assets from https://github.com/lobehub/lobe-icons (MIT; license alongside these files).

- chatgpt.svg: packages/static-svg/icons/openai.svg — black OpenAI knot.
- claude.svg: packages/static-svg/icons/claude-color.svg — Claude orange asterisk; original fill preserved.
- grok.svg: packages/static-svg/icons/grok.svg — black Grok mark.

Downloaded 2026-10-25 from the repository's master branch. These are brand marks, not product certification or affiliation claims. All images are served locally and scaled with fixed dimensions; no remote icon CDN is used.
